# FocusTrace v1.0.8

- 统计页面使用低饱和淡蓝背景，白色统计模块与粉色核心数据形成更清晰的层级。
- 统计范围和待办筛选合并为统一区域，趋势、日历、习惯和记录使用一致的间距与轻量卡片。
- 专注日历点击日期后直接切换到当天统计，保留当前滚动位置，不再跳回页面顶部。
- 日期刷新期间保留当前内容，避免加载状态造成页面高度变化和视觉跳动。
- 趋势模块压缩无效留白，专注记录显示最近条目及手动/计时来源。

Android 8.0 及以上。APK 使用现有 Android Debug 证书签名，可覆盖安装同签名旧版本，无需卸载。

验证：Debug 构建、Lint 和日历联动设备测试通过；Lint 0 错误。
