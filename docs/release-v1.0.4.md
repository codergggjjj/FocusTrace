# FocusTrace v1.0.4

- 统一 Material 3 粉色主题、字体层级、间距和卡片样式。
- 待办使用右下角添加按钮和紧凑的开始图标，保留编辑、完成和补录入口。
- 统计突出专注时长，提供日/周/月分段切换和日期选择。
- 我的页面改为标准设置列表，自动化选项使用开关。

Android 8.0 及以上。APK 启用 R8 优化与资源收缩，非 debuggable，但仍使用原有 Android Debug 证书签名，并非正式发布密钥。相同签名的旧版可以直接覆盖安装，保留本地待办、设置和专注记录，无需卸载。
