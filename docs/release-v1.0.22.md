# FocusTrace v1.0.22

- 「我的 → 专注音乐」支持扫描本机音频，按曲名、歌手或文件夹筛选，一键全选当前结果并批量导入。保留系统文件选择器，导入后显示成功、重复和失败数量。
- 支持为专注选用网易云音乐或 QQ 音乐。在设置中允许通知访问并在所选平台播放后，可在专注页查看曲目，使用平台提供的播放、暂停和切歌操作。
- 自习室加入实验性的 NAT 穿透邀请。双方需手动交换邀请和答复，通过 WebRTC 尝试建立连接。校园网能否连接取决于双方网络，当前没有中继。
- 待办卡片分别显示专注中、已暂停和休息中。

Android 8.0 及以上可安装。APK 沿用 v1.0.21 的签名和包名，可直接覆盖更新。

## 验证

增量构建和 Lint 通过。两项播放器单元测试和十项模拟器专项通过，覆盖本地音频的导入去重、播放与计时联动、两个 Android 媒体会话间的指令隔离，以及同一模拟器内的自习室数据通道双向传输。网易云音乐、QQ 音乐以及两台校园网设备间的穿透尚未进行真机验证。
