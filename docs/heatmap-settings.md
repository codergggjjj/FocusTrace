# 专注热力图与设置编辑

## 热力图
- 对应统计日期区间起始日所在的自然月，周一为首列，空白格补齐，未来日期不可点击。
- 基于已有有效专注统计，包含番茄钟和正向计时；跨日记录整轮归入开始日。
- 五档：0、1–1799 秒、1800–3599 秒、3600–7199 秒、7200 秒及以上。日期数字使用独立底色保证可读性。
- 点击日期显示有效学习时长、完成番茄、分心次数与分心时间；查看当天记录会切换到对应日统计。
- 查询失败可重试，无学习记录的日期仍可查看零值。

## 设置编辑
- 默认番茄分钟 1–1440、默认休息分钟 1–1440、分心阈值秒数 0–86400。
- 自动休息、自动下一轮、浅色/深色/跟随系统。
- 支持输入校验、取消草稿、旋转/页面重建恢复草稿、保存中禁用与失败重试。
- 默认番茄时长用于新建待办；已有待办目标时长不变。休息与轮转设置在新计时读取，进行中的计时仍使用其启动快照。
- 外观保存后应用全局主题；分心阈值按下一次离开事件读取，已记录的离开事件沿用原阈值。
- 提示音与系统通知仍属于下一阶段，不提供暂不可用的播放开关。

沿用 Room / DataStore / Compose，无新增依赖，无数据库结构变更。
