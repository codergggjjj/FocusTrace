# FocusTrace v1.0.21

- 在统计日视图补录时自动带入当前查看的日期，编辑已有记录保留原日期。支持今天、昨天和日历选日，空表单不再立即报错。
- 待办概览明确区分累计已完成和今日专注。修复切到其他应用后息屏、通知栏恢复计时可能误判分心的问题。
- 自习室支持下拉刷新、分享邀请和恢复未解散的房间。新版邀请通过加密连接验证房间身份；重返时可在附近找回地址已变的房间，也可手动忘记。

**安装：** Android 8.0 及以上，使用与 v1.0.20 相同的 debug 签名，提供经过优化的 performance 安装包，可直接覆盖安装。自习室双方都需要更新并重新分享邀请，校园网仍需允许设备互访。
