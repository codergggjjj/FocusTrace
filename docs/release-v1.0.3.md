# FocusTrace v1.0.3

- 在编辑待办中添加专注记录，默认关联当前待办。
- 默认填写当前日期与开始时间，通过分钟数自动计算结束时间，支持快捷时长及自定义输入。
- 历史记录支持手动添加、编辑与确认删除，支持可选任务和备注。
- 手动记录与计时记录共用数据表，计入日、周、月、热力图及任务时长汇总。
- 数据库升级保留原有记录，计时恢复仅读取 TIMER 来源，避免补录干扰活动计时。

Android 8.0 及以上。此 APK 启用 R8 性能优化与资源收缩，仍使用原有 Android Debug 证书签名，可直接覆盖安装同签名旧版本，无需卸载。

验证：47 项回归测试与新增待办入口专项测试通过。
