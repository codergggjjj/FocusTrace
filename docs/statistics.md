# 日、周、月统计

本阶段实现设计书 41–46 节及分类统计。沿用 Compose、Room、StateFlow 和 Navigation，无新增依赖，无数据库结构变更。

## 功能
- 今日、本周、本月切换，上一/下一周期及回到当前周期；不允许浏览未来周期。
- 日期选择保存在 SavedStateHandle，支持页面重建；当前日期与设备时区每 30 秒刷新。
- 有效专注时间、次数、完成番茄、分心次数/时间、专注率、平均分心及首次分心时间。
- 每日专注时间、分心次数、分心时间三种柱形图；点击查看精确值，月视图横向滚动，缺失日期补零。
- 分类汇总、空数据提示、加载及重试。

## 统计口径
- 仅统计已结束的专注（status 3/4 且 endTime 非空），包含提前结束及正在休息的已完成专注。
- 按开始时间归属设备本地日期，跨日整轮归入开始日。现有数据没有完整暂停区间，因此不拆分跨日时长。
- 周一为一周起点，按自然月汇总；使用本地午夜转换查询边界，兼容夏令时。
- 完成番茄要求番茄模式且有效时长达到大于零的计划时长。
- 专注率用总有效专注 /（总有效专注 + 总分心时间），不是单次百分比的平均。
- 分心次数和时间来自持久化事件；首次分心按事件记录顺序取首次离开距开始时间，包含此前暂停时间。无分心记录不参与首次分心均值；无分母显示破折号。
- 分类按关联待办的当前分类显示，改分类会更新历史分类汇总。自由专注、被删除待办或无分类待办归入“未分类 / 自由专注”。
