# 专注音乐

进入专注页，在“专注音乐 → 选择 / 导入”中通过系统文件选择器导入音频。可保存多首音乐，选择后点击播放；单曲循环，支持独立暂停及确认移除。单个文件最多 100 MB，空文件、损坏文件、视频和无法识别的音频会被拒绝；具体格式支持取决于手机的系统解码器。

导入在后台复制音频到应用私有目录，并验证是否包含有效音频。曲目名称、时长和上次选择单独保存到本地 DataStore，不改 Room schema，也不把播放信息写进专注或分心记录。取消文件选择没有副作用，不申请共享存储或网络权限。系统文件选择器的前后台切换仍遵循原有分心规则；可先暂停专注再导入。

播放使用系统 MediaPlayer 异步准备，复用既有计时常驻服务，并在音乐加载或播放时声明 mediaPlayback 服务类型。只在播放期间持有 CPU 唤醒锁以支持息屏播放，不保持屏幕常亮。Activity 重建和返回待办不重新创建播放器。音乐独立于计时：暂停音乐不暂停计时；暂停专注会暂停音乐，继续专注后需手动播放；专注结束、进入休息、切换会话或计时服务销毁会停止并释放播放器。

正常专注中的常驻通知同时提供播放 / 暂停音乐操作。播放前请求系统音频焦点；失去焦点或拔出耳机会暂停，不自动恢复。切换曲目会停止上一首，避免多路声音叠加；本轮暂停后再播放可从暂停位置继续。重启进程后保留曲目和选择，不自动恢复播放。

目前本地备份只保存原有学习数据、设置和背景图片，不包含音频库。迁移到其他手机时需要重新导入音频；恢复学习数据不替换本机音频库。

## 本次验证（2026-10-10）

增量 `assembleDebug`、`lintDebug` 及测试 APK 构建通过，Lint 0 错误、20 项既有提示。API 36 模拟器上的 4 项专项检查通过：音频复制与无效输入拒绝、实际 WAV 播放及暂停/结束联动、专注页音乐入口、原有通知暂停/继续/结束操作。音乐播放专项同时检查切换后台/息屏对应状态后仍可播放，没有改写计时状态。

只重跑了修正后的音频测试，复用已通过的页面与通知结果；未运行全量测试。未验证所有手机解码器、真实来电和物理耳机拔出情形。测试后保留模拟器与 App。

实现参考：[Android 音频焦点](https://developer.android.com/media/optimize/audio-focus)、[MediaPlayer 异步准备](https://developer.android.com/media/platform/mediaplayer/background)、[mediaPlayback 前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types#media)。
