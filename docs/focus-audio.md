# 专注音乐

进入“我的 → 专注音乐”，通过系统文件选择器多选音频。支持批量导入，逐首显示进度；无效文件会跳过并汇总成功/失败数量，已经成功的曲目保留。可选择起始曲目和确认移除，点击专注页播放按钮后按列表顺序播放全部曲目，最后一首结束后回到第一首。每次新建专注会话默认暂停，不自动播放。

单个文件最多 100 MB，空文件、损坏文件、视频和无法识别的音频会被拒绝；具体格式支持取决于手机的系统解码器。

导入在后台复制音频到应用私有目录，并验证是否包含有效音频。曲目名称、时长和上次选择单独保存到本地 DataStore，不改 Room schema，也不把播放信息写进专注或分心记录。取消文件选择没有副作用，不申请共享存储或网络权限。导入入口位于设置页，可在开始专注前准备音乐。

播放使用系统 MediaPlayer 异步准备，复用既有计时常驻服务，并在音乐加载或播放时声明 mediaPlayback 服务类型。只在播放期间持有 CPU 唤醒锁以支持息屏播放，不保持屏幕常亮。Activity 重建和返回待办不重新创建播放器。音乐独立于计时：暂停音乐不暂停计时；暂停专注会暂停音乐，继续专注后需手动播放；专注结束、进入休息、切换会话或计时服务销毁会停止并释放播放器。

正常专注中的常驻通知同时提供播放 / 暂停音乐操作。播放前请求系统音频焦点；失去焦点或拔出耳机会暂停，不自动恢复。切换曲目会停止上一首，避免多路声音叠加；本轮暂停后再播放可从暂停位置继续。重启进程后保留曲目和选择，不自动恢复播放。

目前本地备份只保存原有学习数据、设置和背景图片，不包含音频库。迁移到其他手机时需要重新导入音频；恢复学习数据不替换本机音频库。

## 验证范围

批量导入部分失败、真实音频顺序切换与列表循环、新会话默认暂停、音乐与计时暂停/结束联动，以及设置入口与精简专注页。发布验证结果见 [v1.0.14 发布说明](release-v1.0.14.md)。不运行全量测试；真实来电、物理耳机和不同手机解码器仍需真机检查。
