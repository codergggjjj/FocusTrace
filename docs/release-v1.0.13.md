# FocusTrace v1.0.13

- versionName：1.0.13；versionCode：15。
- Android 8.0 及以上，完全本地运行。
- 安装包：FocusTrace-v1.0.13-performance.apk。开启代码和资源压缩，非调试运行，沿用既有 debug 证书签名。

## 更新内容

- 专注页新增“专注音乐 → 选择 / 导入”，支持保存多首本地音频、选择曲目、播放、暂停与确认移除。
- 音频复制到应用私有目录，单个文件最多 100 MB；记住上次选择，单曲循环，不自动播放。
- 暂停专注会暂停音乐，继续专注后可手动播放；结束专注或进入休息时停止音乐。
- 复用计时常驻服务，支持后台及息屏播放，专注通知增加音乐播放 / 暂停操作。
- 不改数据库结构、计时或分心统计逻辑，不增加网络或共享存储权限。

## 验证与升级

`assemblePerformance`、`lintDebug` 已通过，Lint 0 错误、20 项既有提示。APK 版本已核对为 1.0.13 / 15，签名与 v1.0.12 一致。

已通过专注音乐的 4 项专项检查：导入与无效输入、实际 WAV 播放及暂停/结束联动、页面入口、原有通知操作。复用同一功能代码的通过结果，不重复运行全量测试；具体范围见 [专注音乐说明](https://github.com/codergggjjj/FocusTrace/blob/v1.0.13/docs/focus-audio.md)。模拟器继续保持打开。

使用与旧版本相同的 debug 证书签名，请直接覆盖安装，不要卸载，以保留本地学习数据。音频库暂不包含在本地备份中，换手机后需要重新导入。手机系统解码器、真实来电及物理耳机拔出仍需真机验证。
