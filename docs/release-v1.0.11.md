# FocusTrace v1.0.11

- versionName：1.0.11；versionCode：13。
- Android 8.0 及以上，完全本地运行。
- 安装包：FocusTrace-v1.0.11-performance.apk。开启代码和资源压缩，非调试运行，沿用既有 debug 证书签名。

## 更新内容

- 新增重复待办：每天、工作日（周一至周五）、指定星期。
- 从下个符合日期起，打开待办页生成当天任务；同日防重、不补建错过日期。
- 每次生成的待办独立完成与记录专注。关闭原待办的重复规则或删除原待办，停止后续生成。
- 数据库从 7 显式升级至 8，保留旧待办和专注记录；本地备份兼容重复规则及旧备份。
- 新增分层测试规范和选择性测试脚本，日常验证不默认全量运行。

## 验证与升级

`assemblePerformance`、`lintDebug` 已通过，Lint 0 错误、20 项既有提示。发布 APK 版本为 1.0.11 / 13，签名与 v1.0.10 一致。

重复规则、并发防重、旧数据迁移、备份兼容、编辑页重建与关闭规则共 5 项专项测试通过。复用本次功能验证结果，不重复运行全量测试。旧测试断言和 UiAutomation 组合运行问题仍记录在测试规范中，不宣称全量通过。

请直接覆盖安装，不要卸载。建议升级前保存一份本地备份。数据库升级后不支持直接安装旧版降级。
