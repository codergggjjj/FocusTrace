# 计时通知

- 番茄钟、正向计时和休息期间启动 Android 前台服务，显示常驻通知。
- 专注中提供“暂停”和“结束”，暂停后提供“继续”和“结束”，休息时提供“结束休息”。通知操作继续调用原有 PomodoroEngine，不创建第二套计时状态。
- 正向计时使用正计时器，番茄和休息使用倒计时器；切出应用且进入分心状态时停止通知中的倒计时展示，返回后继续。
- 番茄自然完成会发送“专注完成”，休息结束会发送“休息结束”。主动提前结束和结束正向计时不会额外弹出完成提醒。
- Android 13 及以上首次运行申请通知权限；拒绝权限不会阻止计时和数据保存，但系统可能不在通知栏显示提醒。
- “我的 → 完成提示音”控制完成提醒是否有声音。常驻计时通知始终静音，避免状态更新发声。
- 前台服务使用 Android 14 的 `specialUse` 类型，声明用途仅为用户主动开启的专注和休息计时；应用仍不申请网络权限。

实现不修改 Room schema。服务进程恢复时读取最新 TIMER 会话，并通过持久化时间锚点继续原有计时；没有活动会话时立即停止服务。

Pixel Fold API 36 已验证常驻通知出现、暂停、继续、结束操作和自然完成提醒；对应 2 项通知测试通过。
