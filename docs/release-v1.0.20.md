# FocusTrace v1.0.20

- 新增局域网自习室：两台手机连接同一允许设备互访的 Wi-Fi 后，可以创建或加入房间，查看成员的当前任务、状态和今日专注排行。
- 支持从房间选择待办或开始自由专注。离开房间或房主掉线时，本机的专注计时继续。
- 专注报告支持修改已有记录的有效专注时长，统计随记录更新，保留原计时和分心明细。

**安装：** Android 8.0 及以上。安装包为使用原 debug 签名的 performance 优化版。已安装 GitHub v1.0.19 的用户可直接覆盖更新，无需卸载。

**使用范围：** 自习室不支持公网搜房。开启设备隔离的校园网或访客网络可能无法发现或加入房间；本次发布未做双真机校园网联调。
