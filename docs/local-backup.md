# 本地备份与恢复

“我的 → 备份与恢复”使用 Android 系统文件选择器，用户自行选择文件位置；应用不会联网或自动上传。导出文件为 `FocusTrace-backup.zip`，包含待办、全部专注会话、分心事件、设置，以及已导入的自定义专注背景图片。备份不加密，请妥善保管。

恢复时先完整读取并校验备份格式、版本、记录编号与关联关系，再展示待办、专注和分心记录数量。只有用户点击“确认替换并恢复”后，才会替换本机数据。Room 的四张表在单个事务中替换，保留原记录 ID 和历史任务标题快照；设置与自定义背景路径一并恢复。导入失败不会清空现有 Room 记录。恢复完成后，统计与列表从同一 Room 数据源刷新。

专注、暂停或休息进行中不能导出或恢复，请先结束当前计时。由于恢复会**替换**本机数据，建议恢复前先导出当前数据。不支持合并两个备份，也不支持其他应用或未来未知格式的文件。

备份格式版本为 1，包含 `backup.json` 和可选 `focus_background.jpg`。图片重新写入当前设备的应用私有目录，不沿用旧设备的绝对路径。导入对文件大小、图片尺寸、记录关系和进行中计时状态做校验；不改变 Room schema 或现有计时、统计口径。Android 自动备份仍保持关闭。

备份设置包含每日、每周学习目标。旧版本备份没有目标字段时，恢复后两个目标默认为关闭；超出合法范围的目标值会在恢复前被拒绝。新增可选设置字段保持格式版本 1 兼容。
