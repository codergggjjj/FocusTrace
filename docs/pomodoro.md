# 番茄钟阶段

- 默认 25 分钟专注、5 分钟休息，可为本轮输入 1–1440 分钟。
- 支持自由专注、关联未完成待办、暂停、继续、提前结束确认、自动休息、手动休息及结束休息。
- 自然完成保存计划时长，提前结束保存实际时长；暂停和休息不计入专注时长。本轮结果显示已保存的时长。
- 状态编码固定为 IDLE=0、FOCUSING=1、PAUSED=2、RESTING=3、FINISHED=4，提前结束以 focusSeconds 小于 plannedSeconds 区分。
- Room 版本 2 增加毫秒级累计时间、墙上时间/单调时钟锚点、开机编号及本轮休息设置快照，1→2 迁移保留已有数据。
- 同一次开机用 elapsedRealtime 计算经过时间，不受手动修改系统时间影响。设备重启后回落墙上时间；重启同时修改系统时间无法精确还原，负差值按零处理。
- 刷新延迟时按实际截止时间结算；不会把超出计划的后台时间计入专注。休息同样按截止时间计算。
- 自动下一轮读取现有 DataStore 开关；默认关闭。启用时在观察到休息结束后开始下一轮，不补造离线期间的多轮记录。
- 尚未实现通知、前台服务、正向计时或分心检测。进程被终止时不会即时通知；重新进入专注页时恢复和结算。现阶段后台时间仍计入专注，后续分心阶段再按设计规则处理。

验证覆盖计时状态转换、暂停排除、同次开机修改系统时间、模拟设备重启、延迟刷新、提前结束幂等性、数据库重新打开恢复、1→2 数据迁移及 Compose 操作流程。实际设备覆盖仍待后续 APK 测试阶段扩充。
