# FocusTrace v1.0.17

- versionName：1.0.17；versionCode：19。
- Android 8.0 及以上，完全本地运行。
- 安装包：FocusTrace-v1.0.17-performance.apk；开启代码和资源压缩，非调试运行，沿用既有 debug 证书签名。

## 更新内容

- 手动补录的开始时间改为“小时 / 分钟”两个可滑动的 Material 3 下拉列表，无需输入时间文本。
- 支持选择 00–23 时、00–59 分；新增和编辑记录共用控件，默认当前时间或回填原记录时间。
- 选择后立即按专注时长计算结束时间，保留跨天校验、草稿恢复、待办关联和原有统计口径。
- 增加可选 e2e 技能使用规范，继续采用最小充分测试；尚未接入 e2e 测试运行器，不影响 App 运行依赖。

## 验证与升级

补录优化已通过 Debug 与测试 APK 构建、Lint（0 错误 / 20 项提示）和一条相关设备检查，覆盖默认时间、下拉列表选择、跨天拦截、14:35 + 120 分钟得到 16:35、Activity 重建、保存时间及任务累计 7200 秒。复用本轮相同功能代码的专项结果，没有重复运行全量测试，详见 [手动专注记录](https://github.com/codergggjjj/FocusTrace/blob/v1.0.17/docs/manual-focus-records.md)。

发布用 Performance APK 构建成功，Lint 为 0 错误 / 10 项提示；包内版本已核对为 1.0.17 / 19，签名证书与 v1.0.16 相同。该安装包已在现有 API 36 模拟器上覆盖安装并正常启动，模拟器与 App 页面保持打开。

下载后直接覆盖安装即可保留学习数据，请勿卸载旧版。当前仍使用 debug 签名，不是正式发布 keystore 签名；深色模式和不同系统字号未在本次设备检查中单独验证。
