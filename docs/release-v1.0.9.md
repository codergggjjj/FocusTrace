# FocusTrace v1.0.9

- 优化专注中的页面层级：任务名称、计时与状态更突出，暂停/继续、结束和分心信息更清晰。
- 新增三张内置风景背景图，可选择固定图片或每轮随机选择。随机结果在同一轮专注中保持不变。
- 支持从系统相册导入自定义专注背景；图片缩放后仅保存在应用私有目录，可在设置中移除。自定义图片优先于内置图片。
- 保留原有计时、暂停、结束、分心判定和统计规则。手机切到其他应用后再息屏时，只将息屏前符合阈值的离开时间算作分心；息屏期间继续累计专注。

适用于 Android 8.0 及以上。APK 使用现有 Android Debug 证书签名，可覆盖安装同签名旧版本；尚未配置正式发布密钥。

验证：`assembleDebug`、`lintDebug` 与 `assemblePerformance` 通过；API 36 模拟器检查了专注页面、设置弹窗、自定义图片导入及覆盖安装。虚拟机在验证后保持开启。
