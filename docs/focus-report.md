# 单次专注报告

## 展示与入口

新增独立 Navigation Compose 路由 report/{sessionId}、FocusResultScreen 和 FocusResultViewModel。正在显示的专注自然完成或主动结束时进入报告，自动休息仍保持原计时状态；返回专注页可以继续休息或开始下一轮。专注页也可查看当前最近一轮已结束记录。重启后直接恢复到首页时可通过此入口打开报告，不强制反复弹出。

报告按指定会话 ID 查询，不从“最新会话”或实时计时显示拼装；新一轮开始不会把已经打开的报告替换成新记录。Room @Transaction 一次读取会话和关联分心事件，Repository 计算只读指标，ViewModel 通过 StateFlow 输出。支持加载、重试、记录不存在、尚未结束等状态。

展示任务标题、番茄钟/正向计时、完成/提前结束状态、计划时长、有效专注时长、起止时间、分心次数、分心总时长、平均每次分心、首次分心、专注率及逐条离开/返回时间。

## 指标口径

- 有效专注取已保存 focusSeconds，不包含休息；达到阈值的后台时间已由计时引擎扣除。
- 分心次数和总时间以本会话持久化事件列表计算，确保摘要与逐条明细一致。
- 平均每次 = 分心总秒数 / 次数，四舍五入到整秒；没有事件时显示“—”。
- 首次分心 = 第一条已记录事件的离开时间 − 会话开始时间，显示“开始后”，包含主动暂停。事件以记录 ID 排序，系统时间倒拨导致差值为负时显示“时间不可用”。没有事件显示“未发生分心”。
- 专注率 = 有效专注 /（有效专注 + 分心时间），四舍五入为整数百分比。分母为零时显示“—”，不伪造 100%。
- 沿用现有整秒记录精度，严格模式短于一秒的事件仍可能显示 0 秒；长时长使用时/分/秒，不在 24 小时回绕。
- 设计书示例：3000 秒有效专注、403 秒分心、3 次，专注率 88%，平均每次 134 秒。

## 数据兼容

Room 版本 4 新增 nullable taskTitleSnapshot。新记录保存任务名称，之后待办改名或删除不改变报告标题。迁移回填仍存在的关联待办名称；旧记录没有关联待办时无法区分原始自由专注与已经删除的任务，显示“自由专注 / 原待办不可用”，不猜测原名称。
