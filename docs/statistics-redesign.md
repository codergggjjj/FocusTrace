# 统计页面视觉改版

参考用户提供的卡片式统计截图，保留应用粉蓝主题和现有数据能力。

- 首页只展示所选区间的大号学习时长、次数、番茄数、专注率，分心指标通过详情入口展示。
- 日期/月份选择及前后切换保留；记录列表改为独立可关闭弹窗，保留完整起止时间和报告跳转。
- 日视图展示按开始小时归属的有效时长；周/月视图展示每日趋势。学习、分心次数和分心时长均可切换，柱形显示数值和单位，点击查看精确值。
- 时段统计不是把整段墙钟时间等比例分配到每小时；沿用现有有效专注口径，并在统计说明中明确。
- 热力图保留，点击日期可直接进入当天记录；待办分布使用比例条展示时长与占比。
- 长段规则移入右上角说明，不删除原有统计信息。无记录时显示简洁空态。
- 图表和记录继续使用 LazyRow / LazyColumn 与稳定 key；聚合在已有后台线程执行。无新增依赖、权限或数据库迁移。

## 2026-09 信息架构优化

- 页面顺序调整为总览、趋势、待办分布、开始时段规律、热力图、专注习惯、历史记录。
- 增加年度范围和上一周期对比；年趋势按月聚合，其他周期保持小时或每日粒度。
- 小时聚合扩展到所有周期，用于生成真实的专注开始时段规律；不生成没有数据支撑的结论。
- 历史记录直接显示在统计页底部，保留完整列表弹窗与手动补录入口。
- 任务表没有可靠的完成时间字段，因此总览显示关联待办数，不虚构周期内完成待办数。
- 分类功能已从当前产品移除，分布按待办标题快照统计。

验证：debug / performance 构建与 lint 通过，42 项设备测试通过。已检查手机宽度下有数据的概览截图，以及优化 APK 安装、冷启动和深色主题。修复了月/周切换时图表选中位置越界问题。
