# FocusTrace v1.0.16

- versionName：1.0.16；versionCode：18。
- Android 8.0 及以上，完全本地运行。
- 安装包：FocusTrace-v1.0.16-performance.apk；开启代码和资源压缩，非调试运行，沿用既有 debug 证书签名。

## 更新内容

- 待完成筛选旁新增排序入口，可上移、下移和置顶任务，点击后自动保存。
- 重启、编辑、完成后恢复及本地备份恢复保留排序；新建和自动生成的重复待办默认置顶。
- 已完成列表继续按创建时间倒序，计时与统计规则保持原有行为。
- Room 升级为版本 9，显式 8→9 迁移保留既有任务、专注及分心数据。旧备份仍可恢复。

## 验证与升级

排序功能已通过 Debug 构建、Lint 和 API 36 模拟器上的六项相关检查，覆盖迁移保留数据、排序持久化与旧编辑快照、备份字段兼容、排序页面与 Activity 重建、实际备份恢复和重复待办生成。Lint 为 0 错误、20 项既有提示；复用本轮相同功能代码的专项结果，没有运行全量测试，详见 [待办排序](https://github.com/codergggjjj/FocusTrace/blob/v1.0.16/docs/task-order.md)。

发布用 Performance APK 构建成功，Lint 为 0 错误、11 项提示；包内版本核对为 1.0.16 / 18，签名证书与 v1.0.15 相同。该安装包已在现有 API 36 模拟器上覆盖安装并正常启动，保留 App 页面和模拟器供查看。

下载后直接覆盖安装即可保留学习数据，请勿卸载旧版。当前仍使用 debug 签名，不是正式发布 keystore 签名；真机不同字体大小和横屏布局未在本次专项中逐一验证。
