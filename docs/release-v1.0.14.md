# FocusTrace v1.0.14

- versionName：1.0.14；versionCode：16。
- Android 8.0 及以上，完全本地运行。
- 安装包：FocusTrace-v1.0.14-performance.apk；代码与资源压缩，非调试运行，沿用既有 debug 证书签名。

## 更新内容

- 音乐管理移至“我的 → 专注音乐”，支持一次多选、批量导入、选择起始曲目和移除。
- 每轮专注默认暂停音乐，点击播放后按列表顺序循环全部曲目。
- 批量导入显示进度，单个文件失败不影响已导入曲目；单首最大 100 MB。
- 专注页移除重复标题和标语，收紧布局，使用轻量音乐控制区及更紧凑的分心信息。
- 保留计时、暂停、结束、分心与通知行为，不改数据库结构。

## 验证与升级

Debug、Performance 安装包和测试 APK 构建通过，Lint 0 错误、20 项既有提示。API 36 模拟器上 5 项音乐专项测试通过：批量导入与列表循环、新会话默认暂停、音乐与计时联动、文件校验、设置和专注页面入口。没有运行全量测试。

APK 版本为 1.0.14 / 16，签名与 v1.0.13 一致，可直接覆盖安装保留学习数据，请勿卸载旧版。模拟器保留打开。

音频库仍不包含在本地备份中；不同手机的音频格式支持、真实来电和物理耳机行为仍需真机验证。详见 [专注音乐](https://github.com/codergggjjj/FocusTrace/blob/v1.0.14/docs/focus-audio.md)。
