# FocusTrace v1.0.10

- versionName：1.0.10；versionCode：12。
- Android 8.0 及以上，完全本地运行，无账号和网络权限。
- 安装包：`FocusTrace-v1.0.10-performance.apk`，启用代码/资源压缩，非调试运行，仍使用既有 debug 证书签名。

## 更新内容

- 专注日历格内显示小时数、下方显示日期，保留颜色深浅、日期点击联动和当前滚动位置。
- 统计页统一卡片留白与层级，突出累计时长，保留淡蓝背景和粉色交互。
- 每日 / 每周学习目标：设置目标、查看完成进度，复用有效专注统计；目标设置可备份恢复。
- 本地备份与恢复，包含待办、专注、分心记录、设置和自定义背景。
- 待办学习详情：累计投入、趋势、关联记录与补录入口。
- 已完成专注记录支持确认删除，同步刷新统计；进行中会话不能删除。
- 修复在其他应用息屏后的分心判定、时间分布两位数刻度裁切。

统计仍只计入严格超过 5 分钟的有效专注；未改动数据库 schema、正常计时和手动记录的统计口径。

## 验证

`assembleDebug`、`lintDebug`、`assemblePerformance` 通过；Lint 0 错误、20 项既有提示。发布 APK 在 API 36 模拟器覆盖安装并启动成功，签名 SHA-256 与 GitHub v1.0.9 一致。

日历浅色 / 深色及窄宽布局、日期联动和滚动保留、小时刻度三项专项仪器测试通过。此前学习目标、备份、手动记录及删除等专项验证见对应功能文档；本次不宣称全量仪器测试通过。

直接覆盖安装即可升级，不需要卸载。建议重要数据先在“我的 → 备份与恢复”中保存本地备份。
