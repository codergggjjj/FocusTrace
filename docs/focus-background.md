# 专注页面与背景图

专注页突出任务名称、计时数字和当前状态；暂停/继续与结束操作并列，分心次数、时长、记录入口和判定阈值放在次级区域。背景启用时，页面使用遮罩与半透明内容区保证文字可读；关闭背景时使用 Material 3 主题颜色。页面可滚动，适配窄屏和大字体。

“我的 → 专注背景”可开关背景、在三张内置图片中选择固定图片，或勾选至少一张图片供每轮专注随机选择。随机结果按会话 ID 存入 DataStore，暂停、恢复、页面重建及进程重启后不会重新抽取。开启自定义背景时优先显示用户照片；移除后恢复内置选择。

相册使用 Android 系统图片选择器。选中的图片在后台解码、缩放到最长边不超过 1920 像素，并以 JPEG 存入应用私有目录；应用不需要相册存储权限，也不会上传图片。更换或移除自定义图片时，仅删除此前由应用创建的那一张文件。内置图片为项目生成的风景插画，经 WebP 压缩后随 APK 打包。

这次仅增加视觉与背景设置，不改变专注计时、暂停、结束、分心判定与统计规则。`./gradlew.bat assembleDebug lintDebug` 已通过；在 API 36 模拟器上检查了专注页与设置弹窗，并通过系统图片选择器导入图片，确认正在进行的专注立即显示自定义背景。模拟器在检查后保持运行。
