# FocusTrace v1.0.0

按当前已实现功能发布，不包含设计书中尚未实现的后续功能。

## 下载与安装

下载 Release 附件 `FocusTrace-v1.0.0-debug.apk`，在 Android 8.0 或更高版本设备上安装。系统提示时允许本次使用的浏览器或文件管理器安装应用。

本次发布使用 **debug 签名 APK**。项目尚未配置正式发布 keystore；此安装包不是正式 release 签名构建。签名密钥、本地配置和构建目录不提交到 Git。将来更换签名时可能无法直接覆盖安装，请保留原有数据。

## 当前功能

- 待办创建、编辑、完成、删除、自定义分类，以及任务一键开始。
- 番茄钟与正向计时，暂停、继续、休息和计时状态恢复。
- 前后台分心检测、阈值设置、锁屏和息屏豁免。
- 单次专注报告、日/周/月统计、日期与月份查询、学习起止时间、月度热力图。
- 时长、自动轮转、分心阈值和浅色/深色主题设置。
- 本地 Room / DataStore 保存数据，无需账号或服务器。

## 尚未包含

系统通知与提示音、重复待办与提醒、白噪音、小组件、连续专注天数、数据导出与备份，以及账号和云同步。本次发布不代表 design.md 全部功能已完成。

## 验证

当前功能版本此前已通过 40 项设备测试，包含实际息屏/唤醒测试。本次仅调整应用版本号并构建发布包；assembleDebug 和 lintDebug 成功，APK 签名验证通过，已在 Android 模拟器覆盖安装并冷启动成功。
