# FocusTrace v1.0.6

- 统计页面按“总览、趋势、分布、规律、热力图、习惯、历史记录”重新组织信息层级。
- 新增年度统计和上一周期对比；日、周、月、年均支持前后周期切换和日期选择。
- 专注趋势按日显示小时、按周/月显示每日、按年显示每月，并展示峰值和平均值。
- 新增待办专注分布、24 小时开始时段规律、连续专注天数和本月专注天数。
- 历史记录直接显示在统计页底部，保留手动补录、编辑和报告入口。
- 单次专注报告减少说明文字，突出时长、专注率、分心次数、分心时间和起止时间。
- 所有汇总继续使用统一的专注记录数据源，手动补录和计时记录采用相同统计口径。
- 单次专注严格超过 5 分钟才生成用户可见记录并计入统计；5 分钟整及更短的会话不出现在历史和报告入口中。

Android 8.0 及以上。APK 启用 R8 优化与资源收缩，使用原有 Android Debug 证书签名，可覆盖安装同签名旧版本，无需卸载。

验证：Debug 与 Performance 构建通过，Lint 0 错误；统计聚合 6 项设备测试、统计周期与状态恢复测试、历史记录与报告跳转测试通过。
