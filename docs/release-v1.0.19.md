# FocusTrace v1.0.19

## 更新内容

- “我的”页面新增“应用更新”入口，显示当前安装版本。
- 点击“查看更新与下载”打开 GitHub 最新发布页，查看更新说明并下载 APK。
- 浏览器不可用或被设备策略限制时保留弹窗并提示，支持重试；页面重建后保留弹窗状态。
- 复用当前设置列表、粉色主题和 Material 3 弹窗。

本次提供手动查看发布页的更新入口，不进行后台版本检查、自动下载或自动安装，也不新增网络或安装权限。

## 安装

Android 8.0 及以上。沿用旧版 debug 签名，使用非 debuggable、经过压缩优化的 performance 安装包。下载后直接覆盖安装，无需卸载，可保留原有学习数据。
