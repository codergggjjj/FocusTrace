# 简约视觉优化

## 视觉方向
参考番茄 ToDo 的简洁专注定位，采用 FocusTrace 自己的暖白与低饱和番茄红配色。
保留原生 Compose / Material 3；无新增依赖、图片素材或装饰动画。

## 调整范围
- 明确浅色与深色的配色角色，消除默认紫色卡片，统一文字层级和圆角。
- 共用 PageHeader / TraceCard，细边框、无投影，降低大面积色块的视觉干扰。
- 大屏内容居中并限制到 640dp，手机保持全宽，底部四个导航入口不变。
- 待办：完成数量、完成划线、分类/时长辅助文字、轻量空状态。
- 专注：计时预览、并排时长输入、全宽开始按钮、运行中的环形进度和等宽数字；正向计时不显示虚构进度。较大系统字体隐藏圆环，优先保证数字可读。
- 统计：汇总指标分组、轻量趋势卡片、提高柱形对比度。
- 报告：统一中性色卡片，突出专注率。
- 我的：图标配合设置行，保持只读项的展示语义。

## 可读性
主要浅色文字对比度：正文 14.77:1，辅助文字 5.15:1，主按钮 5.54:1。
深色辅助文字 8.48:1。保留系统字体缩放、滚动和 Material 触控反馈。

## 验证结果
- assembleDebug / lintDebug 通过，30 项既有模拟器测试全部通过。最后的按钮间距微调后重新构建与静态检查通过，并实测运行与结束专注。
- Lint 0 错误、8 项目标 SDK / 依赖版本提示，本次未修改依赖。
- 1080×2092 手机视图检查了待办、专注、统计、我的；深色及 1.5 倍字体的运行计时页检查通过。测试后恢复原有字体和浅色系统设置。
