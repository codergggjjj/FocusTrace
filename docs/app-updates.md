# 应用更新入口

## 使用方式

在“我的”页面的“应用”区域点击“应用更新”，弹窗显示当前安装版本。点击“查看更新与下载”后，交由手机浏览器打开：

[FocusTrace 最新发布](https://github.com/codergggjjj/FocusTrace/releases/latest)

发布页包含版本、更新说明和 APK 附件；下载 APK 后按系统提示覆盖安装。签名必须与已安装版本一致；当前 GitHub 安装包沿用既有 debug 签名。不要卸载旧版，卸载会删除应用私有学习数据。

## 实现范围

- 版本号从本机 PackageManager 读取一次并记住，不写死版本号。
- 复用设置列表、主题和 Material 3 弹窗，不改变导航或数据库。
- 使用 GitHub `/releases/latest` 地址，后续发布新版无需更新此地址。
- 由系统 URI 处理器打开发布页。没有可用浏览器或被设备策略限制时保留弹窗并给出明确提示，支持重试和关闭。
- 弹窗与错误提示通过 `rememberSaveable` 保留，支持页面重建。
- 本次提供手动查看与下载入口，不进行后台版本请求、自动版本比较或应用内 APK 下载/安装；不新增网络权限、安装权限或第三方依赖。
- 查看外部网页时遵循已有前后台与分心规则；正在专注时切到浏览器仍按既有规则判断。

## 验证
