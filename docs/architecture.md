# 第一阶段约定

- 严格保留设计书四张表的字段。时间戳使用 Unix 毫秒，`*Seconds` 使用秒，目标时长使用分钟。
- 会话 `type`：0 为番茄钟，1 为正向计时。后续专注阶段应为 `status` 建立明确且稳定的编码，不依赖枚举顺序。
- 时间区间采用 `[start, end)`，避免相邻日期查询重复计数。当前统计页仅展示记录数；日、周、月聚合留待统计阶段。
- 设计书没有任务日期字段，第一阶段仅提供全部任务查询，不擅自将创建日期当成待办计划日期；待办阶段再明确“今日”与重复规则。
- Room 数据库版本为 1，已导出 schema。不启用破坏性迁移，后续字段修改必须提供迁移。
- 默认分类在数据库创建回调中一次性写入，不在每次应用启动时覆盖用户数据。
- DataStore 未设置时使用默认值；读取 IO 异常回落默认配置，其余读取异常交由页面错误状态处理。
- ProcessLifecycleOwner 的业务注册、进程死亡恢复、精确计时、分心记录和通知均属于后续阶段。
- 发布前需要升级 targetSdk 并完成相应兼容验证，当前版本用于本地开发与安装测试。
