# FocusTrace v1.0.12

- versionName：1.0.12；versionCode：14。
- Android 8.0 及以上，完全本地运行。
- 安装包：FocusTrace-v1.0.12-performance.apk。开启代码和资源压缩，非调试运行，沿用既有 debug 证书签名。

## 更新内容

- 分心时长统一显示为“分钟 + 秒”，例如 125 秒显示“2 分钟 5 秒”。
- 专注页、专注报告、分心明细及统计详情使用相同显示格式。
- 仅调整展示；计时、分心检测、统计口径和数据库结构保持原有行为。
