# FocusTrace v1.0.15

- versionName：1.0.15；versionCode：17。
- Android 8.0 及以上，完全本地运行。
- 安装包：FocusTrace-v1.0.15-performance.apk；开启代码和资源压缩，非调试运行，沿用既有 debug 证书签名。

## 更新内容

- 自动记住音乐列表上次播放到的曲目，下一轮专注或重启 App 后从该曲目开始。
- 进入专注仍默认暂停音乐，点击播放后继续按列表顺序循环。
- 手动选择歌曲可更改起始曲目；保存播放曲目的延迟操作不会覆盖较新的选择。
- 保存曲目时保持当前播放器，保留原有暂停、结束、通知与分心行为。

## 验证与升级

曲目记忆功能已通过 Debug 构建、Lint 和 API 36 模拟器上 4 项音乐专项测试；Lint 0 错误、20 项既有提示。复用同一功能代码的专项结果，没有重复运行全量测试。用例覆盖自动换曲后新会话保留曲目、默认暂停、持久化读取、手动选择优先、移除回退及原有播放联动。

发布用 Performance APK 构建成功，版本已核对为 1.0.15 / 17；签名证书与 v1.0.14 相同。

直接覆盖安装即可保留学习数据，请勿卸载旧版。跨会话恢复到上次曲目的开头，同一轮暂停仍可从暂停位置继续。音频库暂不包含在本地备份中；完整进程重启、真实来电及物理耳机行为没有在本次专项中验证。详见 [专注音乐](https://github.com/codergggjjj/FocusTrace/blob/v1.0.15/docs/focus-audio.md)。
