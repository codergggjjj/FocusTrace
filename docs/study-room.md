# 局域网自习室

1. 两台手机连接同一支持设备互连的 IPv4 Wi-Fi，在底部选择「自习室」。可在「编辑资料」设置昵称和头像。
2. 房主点击「创建自习室」，填写房间名并开始广播。同伴从「附近的自习室」点「加入」。每间房最多 12 人（含房主）。若看不到房间，请确认不是访客网络，也没有启用设备隔离。
3. 在房间点击「开始专注」选择未完成的待办，或以默认番茄时长开始自由专注。从待办页开始、或先开始再进房，同样可同步正在进行的会话。
4. 房主可关闭房间，成员也可自行离开。锁屏或切到其他应用时，房间用独立的常驻通知维持连接；通知也可用来离开或关闭房间。

房间断开时，已经开始的计时、暂停或休息都保留。专注页只显示提示，不会跳转或重置时长。从房间进入专注页时，返回后可在大厅重新加入；不自动重连。有效专注超过 5 分钟才进入历史记录，关联待办和已有统计不变。

发现广播使用 Android NSD，只发布房名、连接信息和协议版本。加入后，在当前 Wi-Fi 内共享头像、昵称、本轮任务名、当前状态和本轮有效专注时长。首版直接加入，不设密码，局域网通信未额外加密，建议在熟悉的 Wi-Fi 使用。不会共享完整待办、分心明细或历史，也不会发送到公网。资料保存在应用私有空间，不包含在学习数据备份中。

成员卡按统计页的今日有效专注秒数排名，相同时并列；进行中的本轮时长单独显示。点击右下角「开始专注」可选择未完成的普通待办或今天的重复任务。首次使用时随机分配英雄昵称与二次元头像，资料可自行修改。房间成员需使用相同版本的自习室协议。
