# 局域网自习室

1. 两台手机连接同一支持设备互连的 IPv4 Wi-Fi，在底部选择「自习室」。可在「编辑资料」设置昵称和头像。
2. 房主点击「创建自习室」，填写房间名并开始广播。同伴从「附近的自习室」点「加入」。大厅会持续搜索，下拉可重新搜索并查看启动时间。每间房最多 12 人（含房主）。若看不到房间，请确认不是访客网络，也没有启用设备隔离。
3. 在房间点击「开始专注」选择未完成的待办，或以默认番茄时长开始自由专注。从待办页开始、或先开始再进房，同样可同步正在进行的会话。
4. 房主可关闭房间，成员也可自行离开。锁屏或切到其他应用时，房间用独立的常驻通知维持连接；通知也可用来离开或关闭房间。

房间断开时，已经开始的计时、暂停或休息都保留。专注页只显示提示，不会跳转或重置时长。从房间进入专注页时，返回后可在大厅重新加入；成员可以点击「重返上次房间」重新连接。有效专注超过 5 分钟才进入历史记录，关联待办和已有统计不变。

发现广播使用 Android NSD，只发布房名、连接信息和协议版本。加入后，在当前 Wi-Fi 内共享头像、昵称、本轮任务名、当前状态和本轮有效专注时长。首版直接加入，不设密码，局域网通信使用 TLS 加密，建议在熟悉的 Wi-Fi 使用。不会共享完整待办、分心明细或历史；默认局域网模式不会向公网传输。资料保存在应用私有空间，不包含在学习数据备份中。

成员卡按统计页的今日有效专注秒数排名，相同时并列；进行中的本轮时长单独显示。点击右下角「开始专注」可选择未完成的普通待办或今天的重复任务。首次使用时随机分配英雄昵称与二次元头像，资料可自行修改。房间成员需使用相同版本的自习室协议。

房主点击「邀请」分享邀请文本，同伴可在大厅「通过邀请加入」粘贴。邀请绕过组播搜索，允许通过当前 Wi-Fi 连接可达的其他 IPv4 子网；不能穿透校园网设备隔离。邀请含房间凭据，只发给信任的同伴。两端需更新至相同协议版本。

房主的房名、端口和邀请凭据保存在本机。正常退到桌面时由前台服务继续主持；被强停、关机或断网期间房间暂时不可连接。再次进入自习室页面可恢复主持；重返时若旧地址连接失败，会在附近按房间公钥标识寻找同一房间；搜索受限时需重新分享邀请。手动关闭或解散会清除房间并使原邀请失效。

新版邀请含房主公钥指纹，TLS 握手验证通过后才发送昵称、任务和加入凭据。附近列表首次加入使用发现广播提供的指纹；后续重返使用本机保存的指纹。旧版邀请需由房主重新分享。暂时离线不会清除邀请，可手动忘记。

## NAT 穿透邀请（实验功能）

两台 Android 设备均连接 Wi-Fi。房主在房间内选择「NAT 穿透邀请 → 生成穿透邀请」，将整段文本私发给同伴。同伴在大厅点「通过 NAT 穿透加入」，粘贴邀请并将生成的连接答复发回。房主在原穿透窗口粘贴答复并连接。每次生成仅支持一位穿透成员，三分钟内完成交换；关闭穿透通道仅断开该连接。再次通过 NAT 加入需要重新交换。

使用系统 WebView 的 WebRTC ICE 和 Cloudflare 的公网 STUN 服务；服务可看到网络地址，邀请及答复也包含连接地址，仅分享给信任的同伴。房间 TLS 字节流在有序可靠的数据通道上传输。没有 TURN 中继；出口禁止 UDP 或双方无法找到可用路径时仍可能失败。
