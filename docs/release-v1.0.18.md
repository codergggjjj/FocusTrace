# FocusTrace v1.0.18

## 更新内容

- 专注页增加上一首、下一首按钮，按音乐列表顺序首尾循环。
- 播放中切歌继续播放，暂停时切歌保持暂停，并记住切换后的曲目。
- 曲目名称与播放控制分行显示，保留长标题空间和 48dp 按钮触摸区域。
- 少于两首音乐时禁用切歌；切换过程中防止重复操作，不修改计时和分心记录。

## 安装

Android 8.0 及以上。安装包使用既有 debug 签名，非 debuggable 的 performance 构建；沿用旧版签名，可覆盖更新，无需卸载。

## 验证

- Debug 和测试 APK 构建成功。
- Performance 发布包构建成功，Lint 0 错误、10 项警告；版本为 1.0.18（20），签名证书与旧版一致，覆盖安装与冷启动成功。
- API 36 专用模拟器 3 项音乐专项通过：手动切歌与首尾循环、播放状态和曲目保存、专注暂停与结束联动、专注页控制按钮显示。
- 未运行全量测试；不同手机解码器、物理耳机与真实来电未专项验证。
