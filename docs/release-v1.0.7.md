# FocusTrace v1.0.7

- 待办页增加今日概览、待完成/已完成筛选和紧凑的专注报告入口，并优化任务卡片的信息层级与小屏适配。
- 专注或休息期间显示常驻通知，可直接暂停、继续和结束；番茄自然完成及休息结束会发送完成提醒。
- “我的”页面增加完成提示音开关，Android 13 及以上首次使用时按系统要求申请通知权限。
- 统计页支持按待办筛选，筛选会同步作用于总览、趋势、分布、时间规律、热力图和历史记录。
- 修复跨小时专注的时间分布：按记录与每个小时的实际重叠时长拆分，不再把全部时长归入开始小时。
- 24 小时时间分布图改为紧凑布局，可在一屏内快速查看全天规律。
- 单次专注严格超过 5 分钟才生成用户可见记录并计入统计；5 分钟整及更短的会话不出现在历史和报告入口中。
- 手动补录和正常计时继续使用相同记录与统计口径，不影响待办、番茄钟、正向计时和分心检测。

Android 8.0 及以上。APK 启用 R8 优化与资源收缩，使用原有 Android Debug 证书签名，可覆盖安装同签名旧版本，无需卸载。

验证：Debug 构建、Android Lint 和测试 APK 构建通过，Lint 0 错误；统计区间拆分、通知状态、页面主题与主要交互的设备测试通过。
