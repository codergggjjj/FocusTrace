# 待办 CRUD 阶段

实现创建、编辑、完成/恢复、确认删除待办；默认分类选择、自定义分类创建和分类筛选。输入校验：标题去除首尾空格后不能为空、最多 100 字，目标时长 1–1440 分钟；分类名称最多 30 字，拒绝已有同名分类。
