# 正向计时阶段

专注首页可切换番茄钟和正向计时。正向计时支持自由专注或关联待办，从零开始，直到主动结束；暂停排除在累计时间之外。复用时间锚点持久化及恢复机制。

正向记录使用设计书 type=1、plannedSeconds=0；不受番茄钟截止时间限制，不自动完成，不进入休息。显示累计分钟和秒，超过一小时或一天不会回绕。本次不修改数据库结构。

新增可控时钟测试覆盖超过 24 小时、暂停期间等待、引擎重新创建、继续后精确累计、结束保存及拒绝休息。新增界面测试覆盖模式切换、暂停、Activity 重建、继续及结束。
