# FocusTrace v1.0.1

本版本将待办流程改为无分类模式：

- 移除创建、编辑待办时的分类选择。
- 移除待办页的分类筛选与新增分类入口。
- 移除任务卡片上的分类文字和统计页的分类汇总。
- 待办卡片的开始按钮与标题并列；删除操作移入编辑界面，并保留二次确认。
- 数据库升级到版本 6，升级时清空旧分类及任务分类关联；已有任务、计时方式、完成状态和专注历史保持不变。
- 保留番茄钟、正向计时、专注报告、分心检测、热力图与日/周/月统计。

APK 使用 `performance` 构建：关闭调试标记、启用 R8 与资源收缩，适合直接安装体验。由于仓库没有正式发布 keystore，APK 仍使用 Android Debug 证书签名，可覆盖安装此前同证书版本，不适合作为应用商店正式签名包。

系统要求：Android 8.0（API 26）或更高版本。

验证结果：优化 APK 构建、Lint、43 项设备测试全部通过；已在 API 36 模拟器覆盖安装并冷启动成功，APK 签名校验通过。
